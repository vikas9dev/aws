## 1. What is AWS?

AWS stands for Amazon Web Services. It's a cloud provider offering on-demand servers and services that scale easily. This is a significant difference from on-premises data centers, where you had to physically order and install servers. On the cloud, you can get resources whenever you need them and scale as required. AWS has revolutionized the industry and powers some of the world's largest websites.

📌 **Example:** Netflix doesn't own a single server; they rent everything from AWS, allowing them to run at scale.

## 2. Creating an AWS Account

Here's a step-by-step guide to creating your AWS account:

1.  **Specify Root User Email Address:** 📧

    - This will be your primary email address.
    - It will be used to log in to your Amazon account.

2.  **Account Name:**

    - Specify a name for your account. 📌 **Example:** `rocco-demo-v3`.

3.  **Verify Your Account:** ✅

    - Follow the verification steps provided.

4.  **Set Root User Password:** 🔑

    - Set a strong password for your root user.
    - Confirm the password.
    - ⚠️ **Warning:** If you lose your root password, you can recover it via email, but it's best to remember both your email and password.

5.  **Account Type:**

    - Specify that this is a personal account.
    - Enter your personal details.

6.  **Credit Card Details:** 💳

    - Enter your credit card information.
    - An authorization of $1 will be placed on your card.
    - 📝 **Note:** This is a pending transaction and will be canceled. It's not a charge.

7.  **Free Tier Usage:** 🆓

    - As long as you stay within the Free Tier limits, you won't be charged.
    - If you exceed the Free Tier, you will be charged.
    - We will show you how to monitor your usage.
    - 💡 **Tip:** If you follow this course, you should remain within the Free Tier limits.
    - 📝 **Note (2026):** For accounts created on or after 15 Jul 2025, the Free Tier works differently. You get up to $200 in credits ($100 at sign-up + up to $100 more). On the **free plan** the account closes after 6 months or when the credits run out, whichever comes first. The old "12 months free" offers apply only to older accounts.

8.  **Identity Verification:** 📞

    - Confirm your identity by providing a phone number.
    - You'll receive an SMS or voice call to verify the number.

9.  **Support Plan:** 🤝

    - Choose a support plan.
    - For this course, we'll use the Basic Support (free), as that's all we need.

10. **Complete Signup:** 🎉

    - Complete the signup process.
    - Congratulations! You're signed up for AWS.

11. **Account Activation:** ⏳

    - It will take a few minutes to activate your account.
    - You'll receive an email when activation is complete.

12. **AWS Management Console:** 🖥️

    - Click on "Go to the AWS Management Console."

13. **Login:**

    - Enter your root user email address and password.
    - You'll be logged into the AWS Console.

14. **Get Started:** 🚀
    - Congratulations! Let's get started with this course.

## 3. AWS Certification Paths: A Learning Journey 🚀

Embarking on your AWS certification journey is exciting! AWS offers a range of certifications, including:

- Foundational
- Associate
- Professional
- Specialty

The ideal path depends on your desired role. Let's explore some common career paths and recommended certifications.

For more information, see:-

- [All certifications](https://aws.amazon.com/certification/).
- [AWS Certification Paths](https://d1.awsstatic.com/training-and-certification/docs/AWS_certification_paths.pdf).

### Architecture Path 🏗️

If you aspire to be a solutions architect, designing, developing, and managing cloud infrastructure, consider this path:

1.  Cloud Practitioner (Optional, but recommended for beginners)
2.  Solutions Architect Associate
3.  Solutions Architect Professional
4.  Security Specialty (For deeper security expertise)

### Application Architecture Path 💻

For roles focused on user interface, middleware, and infrastructure:

1.  Cloud Practitioner (Optional, but recommended for beginners)
2.  Solutions Architect Associate
3.  Developer Associate
4.  DevOps Engineer Professional
5.  Solutions Architect Professional (For deeper expertise)

### Operations Path ⚙️

If you're interested in systems administration, installing, upgrading, and maintaining computer components and software, and integrating automation processes:

1.  Cloud Practitioner
2.  SysOps Administrator Associate (renamed **CloudOps Engineer – Associate**, exam SOA-C03, from 30 Sep 2025)
3.  DevOps Engineer Professional (For deeper expertise)

### Cloud Engineer Path ☁️

For implementing and operating an organization's network computing infrastructure and maintaining data safety:

1.  Cloud Practitioner
2.  SysOps Administrator Associate
3.  Security Specialty
4.  DevOps Engineer Professional (For deeper expertise)
5.  Advanced Networking Specialty (For deeper expertise)

### DevOps Path 🧪

If you're a test engineer embedding testing and quality best practices throughout the software development lifecycle:

1.  Cloud Practitioner
2.  Developer Associate
3.  DevOps Engineer Professional

### Cloud DevOps Engineer Path 🔄

For designing, deploying, and operating large-scale global hybrid cloud computing environments and advocating for automated CI/CD pipelines:

1.  Cloud Practitioner
2.  Developer Associate
3.  SysOps Administrator (Optional)

### Machine Learning Path 🤖
